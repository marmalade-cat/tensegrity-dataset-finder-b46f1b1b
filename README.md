Tensegrity Dataset Finder

A tiny browser-based prototype. Paste an article URL and it will fetch the page, follow immediate links, and report CSV/JSON downloads and common repository links (Figshare, Zenodo, GitHub, Dryad). It will attempt to fetch small files (<=200 KB) to list top-level CSV columns or JSON keys.

Usage: Open index.html in a modern browser, enter a URL, click Scan. No backend required. This is an untested prototype for demonstration only.
